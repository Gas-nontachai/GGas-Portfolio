# Journey Notebook Asset Pack — ThangGas Portfolio

The `svg/` folder contains the seven editable overlays used by the notebook:

- 07 blue paper tape
- 09 bookmark tab
- 10 close button
- 12 star sticker
- 13 heart sticker
- 14 arrow sticker
- 18 paperclip

For precise FLIP transitions and page-flip effects use React/HTML/CSS layout, and use the SVG/PNG assets as graphical overlays. The illustration shapes are editable, not prebuilt 3D rigging.

All assets are original simplified flat cartoon drawings; no user-provided reference image was cropped.
